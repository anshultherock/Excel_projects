# Customer Segmentation Analysis
**Tools:** Excel, Data Cleaning, Pivot, Charts

### Dataset Summary
- Total Customers: 388
- Male: 221, Female: 166 (1 missing - cleaned)
- Customer Types: Regular 218, Frequent 145, New 24
- Sentiment: Positive 316 (81.4%), Negative 72 (18.6%)

### Insights
1. 56% customers are Regular - good retention
2. 81% positive sentiment indicates good service
3. Only 6% new customers - need to focus on acquisition

### Formulas Used
- SUM, IF, VLOOKUP for cleaning
- Pivot Table for segmentation
- Charts for visualization
